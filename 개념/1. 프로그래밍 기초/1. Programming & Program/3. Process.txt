프로세스(Process) :
운영체제가 실행 중인 프로그램을 관리하기 위해 만든 실행 단위

-프로그램이 실제로 실행되고 있는 상태.
-프로세스가 만들어지면 운영체제는 해당 프로그램이 실행될 수 있도록 여러 자원을 할당.
{
메모리 공간
코드
데이터
스택
힙
프로그램 실행 상태
CPU 실행 정보
열려 있는 파일 등의 자원
프로세스를 식별하기 위한 PID(Process ID)
}
-게임을 실행하면 운영체제는 게임 프로세스에 메모리를 할당하고 CPU가 게임의 코드를 실행하도록 관리한다.

----------------------------------------------------------------------------------------------

프로세스와 스레드의 관계

프로세스는 실행 중인 프로그램이며, 하나 이상의 스레드를 포함할 수 있다.

프로세스들은 기본적으로 서로 독립된 메모리 공간을 가지며,
프로세스 내부의 스레드들은 해당 프로세스의 메모리 자원을 공유한다.
