###### **변수(Variable) :**

프로그램이 실행되는 동안 데이터를 저장하고, 필요에 따라 그 값을 변경할 수 있도록 이름을 붙인 저장 공간



**-쓰는 이유 :** 

데이터를 변수에 저장해두면 프로그램의 다른 부분에서 해당 데이터를 사용할 수 있음

ex) 

int hp = 100;

hp = hp - damage;



**-기본 구조**

자료형 변수이름 = 값;

ex) int age = 19;



**-선언과 초기화 :**



*선언 :* 

변수의 존재를 만드는 것.

ex ) int hp;



*초기화 :* 

변수에 처음 값을 넣는 것.

ex) int hp = 100;



**-값 변경 :** 

ex) 

int hp = 100;

hp = 80;

hp = 50;

hp = 0;



**-메모리와의 관계 :** 

단순히 이름만 존재하는 것이 아니라, 프로그램이 실행되면 메모리 공간과 연결되어 데이터를 저장하고 관리



변수 이름

&#x20;  ↓

&#x20; hp

&#x20;  ↓

메모리 공간

&#x20;  ↓

&#x20; 100



프로그램이 실행되면 변수의 값은 프로세스가 사용하는 메모리 공간에 저장.

모든 변수가 단순히 "RAM의 한 칸"에 대응한다고 생각하면 정확하지 않다. 

변수의 저장 방식은 자료형, 지역/필드 여부, 런타임, 최적화 등에 따라 달라질 수 있다.





**-종류 :** 

ex) 

class Player

{

&#x20;   int hp = 100;  // 필드(전역 변수)



&#x20;   void Attack()

&#x20;   {

&#x20;       int damage = 20;  // 지역 변수

&#x20;   }

}
