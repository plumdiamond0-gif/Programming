###### **연산자(Operator) :**

프로그램에서 값이나 데이터를 대상으로 특정 연산이나 동작을 수행하도록 하는 기호 또는 키워드



\-구조 :

연산자

│

├── 산술 연산자

├── 대입 연산자

├── 비교 연산자

├── 논리 연산자

├── 증감 연산자

├── 조건 연산자

└── 기타 연산자



\-산술 연산자 :

+, -, \*, /, %



\-대입 연산자 :

변수에 값을 저장하거나 기존 값을 변경

=, +=. -=, \*=, /=, %=(=제외 복합연산자)



\-비교 연산자 : 

두 값을 비교하여 결과를 true 또는 false로 만듦

==, !=, >, <, >=, <=



\-논리 연산자 : 

여러 개의 조건을 결합하거나 조건을 반대로 만들 때 사용

\&\&(두 조건 모두 true여야 true)

||(둘 중 하나라도 true면 true)

!(값을 반대로 만듦)



\-증감 연산자 :

변수의 값을 1 증가시키거나 1 감소

++, --



\-조건 연산자 : 

조건에 따라 두 값 중 하나를 선택할 때 사용

조건 ? 참일 때 값 : 거짓일 때 값



\-null 관련 연산자 :

변수가 null일 때 특정 값 지정함

변수 ?? 값
