프로그래밍
   ↓
소스 코드 작성
   ↓
컴파일
   ↓
빌드
   ↓
프로그램 생성
   ↓
실행
   ↓
프로세스 생성
   ↓
스레드가 명령 실행
   ↓
CPU가 명령 처리
   ↓
프로그램 동작


                 소스 코드
                     │
                     ▼
              ┌─────────────┐
              │    빌드     			   │
              │           			   │
              │ ┌─────────┐    │
              │ │ 컴파일  		     │   │
              │ └─────────┘    │
              │             			   │
              │ + 리소스     		   │
              │ + 설정      			   │
              │ + 패키징    		   │
              └──────┬──────┘
                     │
                     ▼
                  프로그램
                     │
                     │ 실행
                     ▼
                  프로세스
                     │
          ┌──────────┼──────────┐
          ▼          			▼         		     ▼
       스레드 1    		     스레드 2    		스레드 3
          │          			│          		     │
          └──────────┼──────────┘
                     ▼
                    CPU
                     │
                     ▼
                프로그램 동작





| 개념        		 | 이 흐름에서 하는 역할                     
| --------------------| -------------------------------- 
| **프로그래밍**	 | 프로그램을 만드는 전체 과정                 
| **소스 코드**	 | 프로그래머가 작성한 코드                    
| **컴파일**  	 | 코드를 실행에 필요한 형태로 변환               
| **빌드**   		 | 코드·리소스·설정 등을 모아 실행/배포 가능한 결과물 제작 
| **프로그램** 	 | 실행할 수 있도록 만들어진 결과물              
| **실행**    		 |프로그램의 명령을 실제로 처리하는 과정            
| **프로세스** 	 | 실행 중인 프로그램                       
| **스레드** 		 | 프로세스 내부의 실행 흐름                   
| **CPU** 		 | 스레드의 명령을 실제로 처리하는 하드웨어
