컴파일(Compile) : 
프로그래머가 작성한 소스 코드를 컴퓨터가 실행할 수 있는 형태로 변환하는 과정

-사람이 이해하기 쉬운 코드 → 컴퓨터가 실행하기 쉬운 형태
-컴파일러(Compiler) : 소스 코드를 다른 형태의 코드로 변환해 주는 프로그램

----------------------------------------------------------------------------------------------

-하는 일 : 
1. 문법 검사
문법이 잘못되어 있으면 컴파일 오류를 발생시킨다.

2. 타입 검사
자료형이 맞지 않는 경우도 검사한다.

3. 코드 변환
작성한 소스 코드를 실행 환경이 처리할 수 있는 형태로 변환한다.

4. 최적화
컴파일러가 불필요한 연산을 줄이거나 실행 효율을 높이는 작업을 수행하기도 한다.

----------------------------------------------------------------------------------------------

-컴파일 오류와 런타임 오류 : 

컴파일 오류 : 실행하기 전에 발견되는 오류
런타임 오류 : 컴파일은 성공했지만 프로그램을 실행하는 도중 발생하는 오류

----------------------------------------------------------------------------------------------

-컴파일 vs 실행 : 
[소스 코드]
     ↓
   컴파일
     ↓
[실행 가능한 형태]
     ↓
   실행
     ↓
[프로그램 동작]

컴파일 = 실행하기 위한 형태로 변환하는 과정
실행 = 변환된 코드를 실제로 처리하는 과정

----------------------------------------------------------------------------------------------

-컴파일과 빌드의 차이

	컴파일						빌드
목적	코드를 다른 실행 가능한 형태로 변환	프로그램 전체를 실행/배포 가능한 결과물로 제작
대상	주로 소스 코드					코드 + 리소스 + 설정 등
범위	좁음							넓음
관계	빌드의 일부가 될 수 있음			컴파일을 포함할 수 있음
