###### **반복문(Loop Statement) :**
특정 조건이 만족되는 동안 같은 코드나 작업을 여러 번 반복해서 실행하는 문법

-필요 이유 :
동일한 작업을 여러 코드에 걸쳐 작성하지 않기 위해

-구조 :
┌──────────────┐
│ 		반복 시작    │
└──────┬───────┘
       ↓
┌──────────────┐
│ 		조건 확인    │
└──────┬───────┘
       │
    ┌──┴──┐
  true  	       false
    │              │
    ↓              ↓
 코드 실행       종료
    │
    ↓
 조건 변화
    │
    └──────────→ 조건 확인

-for :
반복 횟수나 반복을 제어하는 값이 명확할 때
for (초기화; 조건; 증감)
{
    반복할 코드
}

-while :
조건이 참인 동안 계속 반복
while (조건)
{
    반복할 코드
}

-do-while :
while과 비슷하지만 조건을 확인하기 전에 코드를 최소 한 번 실행
do
{
    반복할 코드
}
while (조건);

-foreach :
여러 데이터를 가지고 있는 컬렉션의 요소를 하나씩 꺼내 처리
foreach (var item in collection)
{
    Console.WriteLine(item);
}


-break :
반복 조건과 관계없이 특정 상황에서 반복을 즉시 중단

-continue :
현재 반복에서 남은 코드를 건너뛰고 다음 반복으로 넘어감

-nfinite Loop :
반복문의 조건이 계속 true라면 반복이 끝나지 않는 것
