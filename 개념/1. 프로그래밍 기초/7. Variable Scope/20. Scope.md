스코프(Scope) :
변수나 함수 등의 식별자를 사용할 수 있는 코드의 범위

-필요 이유 :
모든 변수가 프로그램 전체에서 자유롭게 사용될 수 있다면 변수 이름이 충돌하거나, 
다른 코드가 의도하지 않게 값을 변경하는 문제가 발생하기 쉽다.
스코프를 사용하면 각 코드 영역에서 필요한 데이터만 사용할 수 있도록 제한

-블록 스코프 :
ex)
if (true)
{
    int number = 10;

    Console.WriteLine(number); // 가능
}

Console.WriteLine(number); // ❌

-함수 스코프 :
void Attack(int damage)
{
    int bonus = 10;
    int totalDamage = damage + bonus;
}
damage, bonus, totalDamage : 함수 밖에서 사영 불가능

-지역 변수 :
ex)
void Attack()
{
    int damage = 10;
}
damage는 함수 밖에서 사용 불가능

-중첩 스코프 :
안쪽 스코프에서는 바깥쪽 스코프의 변수에 접근할 수 있다.
하지만 바깥쪽 스코프에서는 안쪽 스코프의 변수에 접근할 수 없다.

-전역 변수 :
ex)
class Player
{
    int hp = 100;
    void Heal()
    {
        hp += 10;
    }
}
특정 메서드 안에서만 존재하는 지역 변수가 아니라 클래스의 필드이기 때문에 
다른 클래스의 여러 메서드에서 사용할 수 있다.

-생명주기와의 차이 :
스코프 : 어디에서 이름을 사용할 수 있는가?
생명 주기 : 그 데이터가 언제 생성되고 언제 사라지는가
