**HashSet :**
중복되지 않는 데이터를 저장하는 컬렉션



\----------------------------------------------------------------------------------------------



**-데이터 조작 :**



*추가 :*
hashSet.Add(값) -> bool
Add()가 추가에 성공했는지 여부를 bool로 반환
처음 추가 -> true, 이미 존재 : false



*존재 확인 :*
if (names.Contains(데이터))
{ 실행문 }



*제거 :*
hashSet.Remove(데이터)



*개수 :*
hashSet.Count





*집합 연산* :

ex)
HashSet<int> a = new() { 1, 2, 3 };
HashSet<int> b = new() { 3, 4, 5 };



합집합
a.UnionWith(b);



교집합
a.IntersectWith(b);



차집합
a.ExceptWith(b);





\----------------------------------------------------------------------------------------------



**-특징 :**


**1.** 중복을 허용하지 않음

2\. 인덱스로 데이터에 접근이 불가능
3. 값 자체를 기준으로 존재 여부 확인

4\. 배열이나 리스트처럼 데이터의 순서를 관리하기 위한 자료구조가 아니기에
순서가 중요하지 않음

5\. 내부적으로 해시 기반의 자료구조
데이터 -> Hash 함수 -> Hash 값 -> 저장 위치 결정

\-> 적절한 조건에서 존재 여부 확인 매우 빠르게 수행 가능
