###### **Stack :**

데이터를 후입선출(LIFO, Last In First Out) 방식으로 저장하고 관리하는 컬렉션



\----------------------------------------------------------------------------------------------



**-구조 :**


Stack ->
(
TOP
데이터2
데이터3
데이터4
)
->
Push : 데이터 추가
Pop : 데이터 제거



\----------------------------------------------------------------------------------------------



**-특징 :**


Front: 가장 먼저 나갈 데이터가 있는 쪽
Rear: 새로운 데이터가 들어오는 쪽


ex)
numbers.Push(10);
numbers.Push(20);
numbers.Push(30);



들어가는 순서:
10 → 20 → 30


꺼내는 순서:
30 → 20 → 10



\----------------------------------------------------------------------------------------------



**-데이터 조작 :**



*생성 :*
Stack<자료형> 변수명 = new();



*추가 :*
stack.Push(데이터)



*꺼내기 :*
var data = stack.Pop()
가장 위에 있는 데이터가 제거되며 반환



*제거 :*
stack.Clear()



*확인 :*
var data = stack.Peek()
데이터를 꺼내지 않고도 가장 위에 있는 데이터만 확인 가능



*개수 :*
stack.Count
