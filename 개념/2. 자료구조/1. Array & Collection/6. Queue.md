###### **Queue :**

데이터를 선입선출(FIFO, First In First Out) 방식으로 저장하고 관리하는 컬렉션



\----------------------------------------------------------------------------------------------



**-구조 :**


Queue ->
(
Enqueue
Dequeue
)
->
Rear --> 데이터들 --> Front
->
FIFO 순서대로 처리



\----------------------------------------------------------------------------------------------



**-특징 :**


ex)
numbers.Enqueue(10);
numbers.Enqueue(20);
numbers.Enqueue(30);
들어가는 순서와 꺼내는 순서 동일

10 → 20 → 30
↑           ↑
Front       Rear



\----------------------------------------------------------------------------------------------



**-데이터 조작 :**



*생성 :*
Queue<자료형> 변수명 = new();



*추가 :*
queue.Enqueue(데이터);
새로운 데이터는 뒤쪽(Rear)에 추가된다.



*꺼내기 :*
var data = queue.Dequeue();
가장 앞에 있던 데이터가 제거되면서 반환된다.



*확인 :*
var data = queue.Peek();



*개수 :*
queue.Count;



*제거 :*
queue.CLear();



\----------------------------------------------------------------------------------------------



**-다른 자료구조들과의 차이 :**


Stack :
Stack : LIFO
Queue : FIFO



List :
List : 특정 인덱스의 데이터에 직접 접근

Queue : 데이터 처리 순서가 핵심, 가장 먼저 들어온 데이터부터 처리



배열 :
배열 : 고정된 크기의 데이터를 인덱스로 관리
Queue : 데이터를 FIFO 순서로 관리
