배열(Array) :
같은 자료형의 데이터를 여러 개 저장하고, 
각 데이터를 인덱스(Index)를 통해 관리하는 자료구조

----------------------------------------------------------------------------------------------

-구조 :
배열(같은 자료형, 여러 데이터)
->
하나의 배열로 관리
->
인덱스
->
0-데이터, 1-데이터, 2-데이터
각 데이터에는 인덱스(Index)라는 번호가 붙는다.

----------------------------------------------------------------------------------------------

-선언 :
자료형[] 변수명;

배열을 생성하면서 크기를 지정
자료형[] 변수명 = new 자료형[n];
초기값은 기본적으로 0

----------------------------------------------------------------------------------------------

-특징 :
1. 같은 자료형의 데이터를 저장
2. 여러 데이터를 하나의 변수로 관리
3. 인덱스로 각각의 데이터에 접근한다
4. 인덱스는 0부터 시작한다
5. 배열은 생성할 때 크기가 결정되며 이후 크기를 변경할 수 없다.
6. 존재하지 않는 인덱스에 접근하면 오류가 발생한다.

----------------------------------------------------------------------------------------------

-종류 :
1차원 배열
자료형[] 변수명 = {1, 2, 3};

2차원 배열
자료형[,] 변수명=
{
    { 1, 2, 3 },
    { 4, 5, 6 }
};
