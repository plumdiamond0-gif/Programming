리스트(List) :
같은 자료형의 여러 데이터를 순서대로 저장하고 관리할 수 있는 컬렉션

----------------------------------------------------------------------------------------------

-구조 :
List
(
여러 데이터 -> 인덱스로 접근
동적 크기 -> Add / Remove
)

----------------------------------------------------------------------------------------------

-데이터 조작 :

생성 
using System.Collections.Generic;
List<T> 변수명 = new List<T>();

데이터 추가 
list.Add(데이터)
List
 ↓
데이터 추가
 ↓
필요한 만큼 크기 증가

데이터 삭제 
list.Remove(데이터)
list.RemoveAt(n);
list.Clear()

개수 
list.Count
배열의 Length와 비슷한 역할

데이터 확인 
list.Contains(데이터)
있다면 true, 없으면 false

----------------------------------------------------------------------------------------------

-동적 크기 :
배열은 처음부터 크기가 정해지지만, 
리스트는 필요에 따라 데이터 추가,삭제 가능

List가 동적으로 크기가 늘어난다고 해서 데이터를 추가할 때마다 
실제 메모리 공간을 정확히 한 칸씩 늘리는 것은 아니다.

내부적으로 Capacity(용량)를 가지고 있으며, 
필요할 경우 더 큰 공간을 확보하여 데이터를 옮긴다.
Count    → 현재 들어 있는 요소의 개수
Capacity → 현재 확보해 놓은 저장 공간의 크기

----------------------------------------------------------------------------------------------

-다른 자료형들과의 차이 :
배열과의 차이 :

배열
1. 크기 고정
2. 직접적인 크기 증가, 요소 삭제 불가능
3. 크기가 정해진 데이터가 용도

List
1. 크기 동적
2. Add(), Remove(), RemoveAt()
3. 크기가 변하는 데이터가 용도
