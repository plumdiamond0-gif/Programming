딕셔너리(Dictionary) :
키(Key)와 값(Value)을 한 쌍으로 저장하는 컬렉션

----------------------------------------------------------------------------------------------

-구조 :
Dictionary<TKey, TValue>
          │       │
          │       └── Value의 자료형
          └────────── Key의 자료형
Key를 이용해 Value 검색

----------------------------------------------------------------------------------------------

-필요 이유:
배열이나 리스트에서는 숫자 인덱스로 데이터 찾음
딕셔너리에서는 원하는 형태의 Key로 직접 사용 가능
-> 특정 이름이나 ID 등을 이용해서 데이터를 찾아야 하는 경우 매우 유용

----------------------------------------------------------------------------------------------

-데이터 조작 :

추가 :
dictinary.Add(Key, Value);

사용 :
자료형 변수명 =dictinary[Key];
dictionary[Key"] -> Key 검색 -> Value

if (dictionary.TryGetValue(Key, out 자료형 변수명))
{실행문}
TryGetValue("Plum") -> Key 존재?
Yes : Value 반환
No : false

수정 :
dictionary[Key] = 값;

제거 :
dictionary.Remove(Key);

개수 :
dictionary.Count

Key 존재 확인 :
dictionary.ContainsKey()
Key 존재?
Yes : true
No : false

----------------------------------------------------------------------------------------------

-특징 :
Key는 중복될 수 없다
Dictionary에서 Key는 고유해야 한다.
Key를 이용해 Value를 찾기에 같은 Key값으로 두번 Add하면 오류 발생
그러나 Value는 중복 가능

단순히 데이터를 위에서부터 하나씩 찾는 구조가 아니라 해시(Hash)를 이용하여 
적절한 조건에서 Key를 빠르게 찾을 수 있도록 만들어져 있다.
Key
 ↓
Hash 계산
 ↓
저장 위치 결정
 ↓
Value 찾기
