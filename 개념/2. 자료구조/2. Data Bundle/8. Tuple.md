**Tuple :**
서로 다른 여러 개의 값을 하나의 묶음으로 묶어서 다루는 자료형



\----------------------------------------------------------------------------------------------



**-구조 :**



Tuple

├── 자료형1   → 값

└── 자료형2 → 값



\----------------------------------------------------------------------------------------------



**-데이터 조작 :**



*생성 :*
(자료형1, 자료형2) 변수명 = (값1, 값2);



*접근 :*



요소에 이름이 지정되지 않은 경우 ->

tuple.Item1

tuple.Item2



요소에 이름 지정 ->

(자료형1 이름1, 자료형2 이2) 변수명 = (값1, 값2);

tuple.name1

tuple.name2



*분해 :*



ex)

(int hp, int level) GetPlayerInfo()

{

&#x20;   return (100, 10);

}

(int hp, int level) = GetPlayerInfo();



\-> 듀플 분해(Deconstruction)



*교환 :*

일반적으로는 임시 변수가 필요

ex)

int temp = a;

a = b;

b = temp;



튜플 :

ex)

a = 10

b = 20

(a, b) = (b, a);



\----------------------------------------------------------------------------------------------



\-특징 :



\----------------------------------------------------------------------------------------------



**-다른 자료구조들과의 차이 :**



배열

배열 : 은 종류의 데이터를 여러개 저장할 때

Tuple  : 서로 관련된 여러 값을 하나의 묶음으로 표현할 때 사용

&#x20;

Class

목적이 다름

Class : 객체를 정의하고 그 객체의 데이터와 기능을 체계적으로 관리

Tuple : 간단하게 여러 값을 묶어서 전달



다른 자료구조들(컬렉션)과 튜플(자료형의) 차이

컬렉션 : 여러 개의 데이터를 모아서 관리하는 자료구조

튜플 : 러 개의 값을 하나의 묶음으로 묶는 것



\----------------------------------------------------------------------------------------------
