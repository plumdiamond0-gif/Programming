**Heap :**
프로그램 실행 중에 동적으로 생성되는 객체나 데이터를 저장하는 메모리 영역



Stack은 메서드 실행에 필요한 정보를 관리하는 메모리 영역이고, 참조형 변수는 객체 자체가 아니라 객체를 가리키는 참조를 저장한다.



\----------------------------------------------------------------------------------------------



**-Stack과 비교 :**



Stack                         	 Heap

────────────────────────────────────

메서드 실행 정보              	동적으로 생성된 객체

지역 변수 등                 	클래스 객체

빠른 생성/제거               	GC에 의해 관리

메서드 종료와 함께             	필요 없어지면

Frame이 제거될 수 있음        나중에 정리됨



\----------------------------------------------------------------------------------------------



**-사라지는 시점 :**

C#에서는 Garbage Collector(GC)가 사용되지 않는 객체를 찾아서 메모리를 정리한다.



ex)

Player player = new Player();



Stack                  Heap

player ──→ \[Player 객체]



player = null;



Heap에 있는 Player 객체를 더 이상 아무도 참조하지 않으므로 GC가 나중에 제거할 수 있는 대상이 된다.

null이 되는 순간 즉시 삭제되는 건 아니다.
