###### **참조형 (Reference Type) :**

변수가 객체 자체가 아니라 객체를 가리키는 참조(Reference)를 가지고 있는 형태



**-예)**

class

string

array

object

delegate



ex)

class Player

{

&#x20;   public int HP;

}



Player player1 = new Player();

player1.HP = 100;



Player player2 = player1;



player2.HP = 50;



player1.HP → 50

player2.HP → 50



player1과 player2가 같은 객체를 가리키고 있음
