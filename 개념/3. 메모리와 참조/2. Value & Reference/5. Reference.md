###### **참조(Reference) :**

어떤 객체가 저장된 위치를 가리키는 정보



\----------------------------------------------------------------------------------------------



**-복사 :**

참조형 변수를 다른 변수에 대입하면 객체가 복사되는 것이 아니라 참조가 복사된다.



ex)

Player player1 = new Player(); 

player1.HP = 100; 



Player player2 = player1; 

player2.HP = 50;

\->

player1.HP = 50

player2.HP = 50



player1과 player2가 같은 객체를 가리키고 있기 때문에, player2.HP를 변경하면 player1.HP도 변경된다.



\----------------------------------------------------------------------------------------------



**-값형과 차이 :**



값형은 대입할 때 값 자체가 복사된다.

ex)

int a = 10;

int b = a;

b = 20;

a → 10

b → 20

서로 다른 값을 가지고 있다.



참조형 :

ex)

Player a = new Player();

Player b = a;

a ──┐

&#x20;   ↓

&#x20; \[객체]

&#x20;   ↑

&#x20;   └── b

두 변수가 같은 객체를 가리킨다.



\----------------------------------------------------------------------------------------------



**-참조 소멸 :**



**ex)**

Player player = new Player();

player = null;



참조가 null이 되면 player는 더 이상 객체를 가리키지 않는다.



더 이상 접근할 수 없는 객체는 Garbage Collector(GC)가 나중에 메모리를 회수한다.
