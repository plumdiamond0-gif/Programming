**Struct :**
여러 데이터를 하나의 값으로 묶어서 표현하는 값 타입(Value Type)



\----------------------------------------------------------------------------------------------



**-구조 :**



struct 변수명

{

&#x20;   public 자료형1 변수명1;

&#x20;   public 자료형2 변수명2;

&#x20;   public 자료형3 변수명3;

}

\----------------------------------------------------------------------------------------------



\-특징 :

1. 값 자체가 복사됨.



ex)

PlayerInfo player1 = new PlayerInfo();

player1.Level = 10;



PlayerInfo player2 = player1;



player2.Level = 20;



player1.Level → 10

player2.Level → 20



반면 클래스는 참조 타입이라 객체를 가리키는 참조 자체가 복사됨





2\. 여러 데이터 하나로 묶기 가능

하나의 Struct 안에 다양한 자료형의 변수들 넣기 가능



\----------------------------------------------------------------------------------------------



**-Class와의 차이 :**



Class 

타입 : 참조 타입

복사 : 참조가 복사

상속 : 가능

null : 가능

용도 : 객체 및 복잡한 기능, 단순한 데이터를 하나의 값으로 표현할 때

생성 : new 사용



Struct

타입 : 값 타입

복사 : 값 자체가 복사

상속 : 클래스 상속 불가능

null : 기본적으로 불가능

용도 : 작은 데이터 묶음, 데이터와 기능이 많고 하나의 객체로서 행동해야 하는 경우

생성 : new 사용 가능



\----------------------------------------------------------------------------------------------
