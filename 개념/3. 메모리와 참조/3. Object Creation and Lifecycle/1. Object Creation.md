###### **객체 생성(Object Creation) :**

클래스나 구조 등을 바탕으로 실제로 사용할 수 있는 객체를 메모리에 생성하는 것



\----------------------------------------------------------------------------------------------



객체 생성

→ 클래스 등의 타입을 바탕으로 실제 인스턴스를 만드는 것



클래스

→ 객체의 설계도



객체

→ 설계도를 바탕으로 만들어진 실제 인스턴스



\----------------------------------------------------------------------------------------------



**-변수와의 차이 :**



Player player = new Player();

player

→ 객체를 가리키는 참조를 가진 변수

Player 객체

→ 실제로 생성된 객체



변수는 객체 자체가 아니라 객체를 참조할 수 있다.



\----------------------------------------------------------------------------------------------



**-특징 :**

1. 객체 생성 시 필드는 생성자로 인해 기본값으로 초기화됨
2. 같은 클래스를 이용해 여러개의 객체 생성 가능
