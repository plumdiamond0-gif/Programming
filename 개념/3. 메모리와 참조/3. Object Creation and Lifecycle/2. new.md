###### **new :**

C#에서 새로운 객체나 값형 인스턴스를 생성할 때 사용하는 키워드



\----------------------------------------------------------------------------------------------



**-ex) :**

Player player = new Player();

new Player()

&#x20;     ↓

Player 인스턴스 생성

&#x20;     ↓

player가 생성된 인스턴스를 참조



\----------------------------------------------------------------------------------------------



**-객체 생성과의 관계 :**

클래스는 타입을 정의한거지, 객체가 만들어진 것은 아니다.

실제로 객체를 만드려면 new를 사용



\----------------------------------------------------------------------------------------------



**-생성자 실행 :**

객체 생성 시 필드는 생성자로 인해 기본값으로 초기화됨

new는 객체를 생성하는 과정과 생성자 호출을 연결하는 역할을 한다.



\----------------------------------------------------------------------------------------------
