###### **null :**

참조형 변수가 현재 어떠한 객체도 참조하고 있지 않음을 나타내는 값



\----------------------------------------------------------------------------------------------



**-ex) :**

Player player = null;

player

&#x20; │

&#x20; ↓

&#x20;null

→ 참조할 객체가 없음



\----------------------------------------------------------------------------------------------



**-특징 :**

1. 객체가 아님
2. new와 반대됨
3. 접근 시 NullReferenceException 발생



\----------------------------------------------------------------------------------------------
