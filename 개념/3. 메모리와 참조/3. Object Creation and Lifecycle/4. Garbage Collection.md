###### **Garbage Collection(GC) :**

프로그램에서 더 이상 사용할 수 없는 객체를 찾아 그 객체가 사용하던 메모리를 자동으로 회수하는 기능



\----------------------------------------------------------------------------------------------



**-필요 이유 :**

객체들이 계속 만들어지면 메모리 사용량도 계속 증가한다.



그런데 어떤 객체가 더 이상 필요하지 않은데도 메모리에 계속 남아 있다면,

필요없는 객체가 계속 메모리를 차지해 메모리가 낭비되는 문제 발생.



GC는 이런 더 이상 접근할 수 없는 객체를 찾아 메모리를 회수한다.



\----------------------------------------------------------------------------------------------



**-Garbage :**

프로그램에서 더 이상 접근하거나 사용할 수 없는 객체



**-삭제 조건 :**

객체사 null이 됐다 해서 즉시 메모리에서 삭제되는 건 아니다.

참조가 없어져서 GC가 회수할 수 있는 상태가 되는 거일 뿐.

참조가 하나라고 있으면 Garbage가 아님.



\----------------------------------------------------------------------------------------------



**-특징 :**

프로그래머가 직접 메모리 해제하지 않아도 되게 함.

메모리를 조사하고 정리하는 작업이 필요하기에 CPU를 사용한다
