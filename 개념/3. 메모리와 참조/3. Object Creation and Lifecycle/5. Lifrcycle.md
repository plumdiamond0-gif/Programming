###### **객체의 생명주기(Object Lifetime) :**

객체가 생성된 순간부터 더 이상 필요하지 않아 메모리에서 회수될 때까지의 과정



\----------------------------------------------------------------------------------------------



**-흐름 :**

객체 생성

&#x20;  ↓

객체 초기화

&#x20;  ↓

객체 사용

&#x20;  ↓

더 이상 접근할 수 없음

&#x20;  ↓

Garbage Collection 대상

&#x20;  ↓

메모리 회수



\----------------------------------------------------------------------------------------------



new를 통해 새로운 인스턴스 생성 -> 객체 생명주기의 시작

생성자 호출로 초기화

참조를 통해 객체 사용

객체가 null이 될 시, 더 이상 참조 불가(객체 즉시 삭제 아님)

더 이상 접근할 수 없게 되면(객체를 가리키는 참조가 모두 사라지면) GC에 의해 메모리 회수
