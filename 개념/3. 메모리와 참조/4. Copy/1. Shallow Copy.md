**얕은 복사 (Shallow Copy) :**
객체를 복사할 때 내부의 참조형 데이터까지 새로운 객체로 복사하지 않고, 기존 객체에 대한 참조를 그대로 복사하는 방식​

객체 자체는 새로 만들어질 수 있지만 내부에서 참조하고 있는 객체는 원본과 복사본이 공유한다.



\----------------------------------------------------------------------------------------------



**-특징)**



ex)

Player player2 = new Player(); 

player2.Name = player1.Name; 

player2.Weapon = player1.Weapon;



Player 객체는 서로 다르지만 Weapon 객체는 같은 객체를 참조

\-> 한쪽의 Weapon 값을 바꾸면 다른 쪽의 값도 바뀌는 문제 발생



값형 필드 → 값이 복사됨 

참조형 필드 → 참조가 복사됨 → 같은 객체를 공유



\----------------------------------------------------------------------------------------------



**-깊은 복사와 비교 :**

얕은 복사 : 내부 객체를 공유한다.

깊은 복사 : 내부 객체까지 새로 복사한다.
