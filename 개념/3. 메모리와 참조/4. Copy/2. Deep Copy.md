**깊은 복사 (Deep Copy) :**
객체를 복사할 때 객체 내부의 참조형 데이터가 가리키는 객체까지 새롭게 복사하는 방식

원본 객체와 복사된 객체가 서로 독립적인 객체 구조를 갖게 된다.



\----------------------------------------------------------------------------------------------



**-특징)**



ex)

player1.Name = "Plum";

player1.Weapon = new Weapon(); 

player1.Weapon.Damage = 100;



player2.Name = player1.Name; 

player2.Weapon = new Weapon(); 

player2.Weapon.Damage = player1.Weapon.Damage;





Player뿐만 아니라 내부의 Weapon 객체도 새로 만든다.

\-> 서로 다른 Weapon 객체를 갖고 있기에 복사본을 수정해도 원본에 영향 주지 않음
