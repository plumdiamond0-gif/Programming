**ref :**
메서드의 매개변수로 변수의 참조를 전달하는 키워드



\----------------------------------------------------------------------------------------------



**-특징)**



ex)

void Change(ref int value) { value = 20; } 

int number = 10; 

Change(ref number); 

Console.WriteLine(number); -> 20



ref를 사용하면 value가 number를 직접 참조한다.

\-> value = 20으로 변경하면 원본 변수도 변경된다.



매서드 선언부와 호출부 모두에 작성해야 함.



원본 변수 직접 변경 가능



호출하기 전에 반드시 값 초기화 필요

ref는 이미 존재하는 변수의 참조를 전달하기 때문에 호출 전에 값이 할당되어 있어야 한다.



\----------------------------------------------------------------------------------------------



**-일반 매개변수와 차이 :**

일반 매개변수 -> 값 전달

ref -> 변수 자체를 참조해 전달



\----------------------------------------------------------------------------------------------



**-참조형과의 차이 :**

참조령 -> 객체를 가리키는 참조를 값으로 전달

ref -> 변수 자체를 참조로 전달
