###### **out :**

메서드에서 값을 외부로 전달하기 위해 변수의 참조를 전달하는 키워드



\----------------------------------------------------------------------------------------------



**-특징)**



ex)

void GetValue(out int value) { value = 100; } 

int number; 

GetValue(out number); 

Console.WriteLine(number); // 100



number는 값을 할당하지 않은 상태로 GetValue()에 전달했지만, 

메서드 내부에서 value에 값을 할당했기 때문에 호출이 끝난 후 number에 100이 들어간다.



메서드가 값을 반드시 만들어서 전달해야 한다.



\----------------------------------------------------------------------------------------------



**-ref와의 차이 :**





**ref**

**참조 전달 : O**

**호출 전 초기화 :	필요**	

**메서드 내부에서 값 읽기 : 가능**

**메서드에서 값 할당 :	선택**

**주요 목적 : 기존 값 수정**



**out**

**참조 전달 : O**

**호출 전 초기화 : 필요 없음**

**메서드 내부에서 값 읽기 : 할당 전에는 불가능**

**메서드에서 값 할당 : 필수**

**주요 목적 : 값을 외부로 반환**
