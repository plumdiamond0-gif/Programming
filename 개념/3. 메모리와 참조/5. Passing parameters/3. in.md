###### **in :**

변수의 참조를 메서드에 전달하면서, 메서드 내부에서 해당 값을 변경하지 못하도록 하는 키워드



\----------------------------------------------------------------------------------------------



**-특징)**



ex)

void Print(in int value) { Console.WriteLine(value); } 

int number = 100; 

Print(in number);



값 변경 불가능 -> 값을 읽기만 할 때 사용



크기가 큰 구조체를 복사하지 않고 읽기만 해야할 때 유용



\----------------------------------------------------------------------------------------------
