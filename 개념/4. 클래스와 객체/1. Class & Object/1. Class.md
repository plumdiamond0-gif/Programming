**클래스 (Class) :**

객체를 만들기 위한 설계도(틀)

객체가 가져야 할 데이터(필드)와 기능(메서드)을 하나로 묶어 정의한다.



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public string name;

&#x20;   public int hp;



&#x20;   public void Attack()

&#x20;   {

&#x20;       Console.WriteLine("공격!");

&#x20;   }

}

Player player = new Player();



클래스 자체는 설계도이므로, 실제로 사용하려면 new를 이용해 객체(instance)를 생성해야 한다.



\----------------------------------------------------------------------------------------------



**-특징 :**

참조형(reference type)이다.

클래스 변수에는 객체 자체가 아니라 객체를 가리키는 참조(reference)가 저장된다.

new를 사용하여 객체를 생성한다.

객체마다 서로 다른 데이터를 가질 수 있다.

필드, 메서드, 프로퍼티, 생성자 등을 포함할 수 있다.

객체가 더 이상 사용되지 않으면 Garbage Collection의 대상이 될 수 있다.
