**Object (객체) :**

클래스라는 설계도를 바탕으로 메모리에 실제로 만들어진 하나의 실체



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public string name;

&#x20;   public int hp;



&#x20;   public void Attack()

&#x20;   {

&#x20;       Console.WriteLine("공격!");

&#x20;   }

}

Player player = new Player();



Player        → 클래스(설계도)

new Player()  → 실제로 생성된 객체

player        → 그 객체를 가리키는 참조 변수



\----------------------------------------------------------------------------------------------



**-특징 :**



객체는 데이터를 가진다

같은 클래스로 여러 객체를 만들 수 있으며, 각각 서로 다른 데이터를 가지기 가능



객체는 기능도 사용할 수 있다

객체에 정의된 메서드를 호출 가능
