**this :**

재 객체 자기 자신을 가리키는 키워드

클래스 내부에서 this를 사용하면 현재 메서드나 생성자를 실행하고 있는 객체를 의미한다.



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public string name;



&#x20;   public void SetName(string name)

&#x20;   {

&#x20;       this.name = name;

&#x20;   }

}

this.name → Player 객체의 필드

name      → 메서드의 매개변수



this는 클래스의 현재 객체를 가리키는 것이므로, static 멤버에서는 사용할 수 없다.



\----------------------------------------------------------------------------------------------
