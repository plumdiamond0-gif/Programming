**필드 (Field) :**

클래스나 구조체 내부에 선언되어 객체가 가지고 있는 데이터를 저장하는 변수

&#x20;

\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public string name;

&#x20;   public int hp;

&#x20;   public float speed;

}

name, hp, speed -> 필드



\----------------------------------------------------------------------------------------------



**-특징 :** 

각 객체는 서로 독립적인 필드 값을 지닌다.

접근 제한자를 사용할 수 있다



\----------------------------------------------------------------------------------------------



**-지역 변수와의 차이 :**

구분		필드				지역 변수

선언 위치	클래스 내부		메서드 내부 등

역할		객체의 데이터 저장	일시적인 계산/작업

수명		객체의 수명과 관련	해당 블록의 실행 동안

접근		객체를 통해 접근 가능	선언된 범위에서만 사용



\----------------------------------------------------------------------------------------------



**-프로퍼티와의 차이 :** 

**ex)**

**class Player**

**{**

&#x20;   **private int hp;       // 필드**



&#x20;   **public int HP         // 프로퍼티**

**}**



필드 → 실제 데이터를 저장하는 변수

프로퍼티 → 필드에 접근하는 방법을 제어하는 기능
