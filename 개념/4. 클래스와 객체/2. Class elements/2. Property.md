###### **프로퍼티 (Property) :**

객체의 필드에 접근하거나 값을 변경하는 방법을 제어하는 멤버

필드의 값을 안전하고 규칙적으로 읽거나 수정할 수 있게 해주는 통로



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   private int hp;



&#x20;   public int HP //프로퍼티

&#x20;   {

&#x20;       get { return hp; }

&#x20;       set { hp = value; }

&#x20;   }

}



\---------------------------------------------------------------------------------------------



**-필요 이유 :**

값의 변경을 제한하거나 검증할 수 있다.

단순한 필드였다면 직접 값을 넣을 수 있지만, 프로퍼티를 사용하면 값을 넣을 때 규칙을 적용할 수 있다.



\---------------------------------------------------------------------------------------------



**-get과 set**  



ex)

public int HP

{

&#x20;   get { return hp; }

&#x20;   set { hp = value; }

}





get :

int currentHp = player.HP;

get이 실행되어 hp의 값을 가져온다.



set :

player.HP = 100;

set 실행

value -> 프로퍼티에 대입하려는 값



\----------------------------------------------------------------------------------------------



**-특징 :**



get만 작성하면 외부에서 값을 읽을 수 있지만 변경할 수 없는 프로퍼티를 만들 수 있다.

\-> 읽기 전용 프로퍼티



ex)

class Player

{

&#x20;   public int HP { get; set; }

&#x20;   public string Name { get; set; }

}

특별한 처리가 필요하지 않다면 간단하게 작성 

\-> C#이 자동으로 숨셔진 저장 공간(백킹 필드) 생성



\----------------------------------------------------------------------------------------------



**-프로퍼티와의 비교 :**



&#x09;	필드			프로퍼티

역할 		데이터 저장	데이터 접근 제어	

형태 		변수			get, set

검증/처리	  직접 구현 필요	  get/set에 구현

사용법 	player.hp		player.hp
