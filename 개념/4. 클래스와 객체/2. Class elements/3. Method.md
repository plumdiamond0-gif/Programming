**메서드 (Method) :**

클래스나 구조체 내부에 정의되어 특정 작업을 수행하는 코드 블록

객체가 할 수 있는 행동이나 기능을 정의한 것



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public void Attack() -> 메서드

&#x20;   {

&#x20;       Console.WriteLine("공격!");

&#x20;   }

}



\----------------------------------------------------------------------------------------------



**-반환형 :**

메서드가 실행된 후 어떤 값을 반환할지 지정한다.

ex)

int -> 반환형 GetHP()

{

&#x20;   return 100;

}



\----------------------------------------------------------------------------------------------



**-매개변수 :**

메서드가 작업하는 데 필요한 값을 외부에서 전달받는 변수

호출할 때 값을 전달

ex)

void Attack(int damage -> 매개변수)

{

&#x20;   Console.WriteLine($"{damage}의 데미지!");

}



\----------------------------------------------------------------------------------------------



**-반환값 :**

메서드가 작업한 결과를 호출한 곳으로 돌려줄 수 있다.

ex)

int Add(int a, int b)

{

&#x20;   return a + b -> 반환값;

}



\----------------------------------------------------------------------------------------------



**-메서드 오버로딩 :**

ex)

void Attack()

{

&#x20;   Console.WriteLine("일반 공격");

}

void Attack(int damage)

{

&#x20;   Console.WriteLine($"{damage} 데미지 공격");

}



Attack();

Attack(100);

매개변수에 따라 적절한 메서드가 선택된다.
