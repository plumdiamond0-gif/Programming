**생성자 (Constructor) :**

객체가 생성될 때 자동으로 실행되는 특별한 메서드

주로 객체가 만들어질 때 필드나 프로퍼티를 초기화하는 역할을 한다.



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public string name;

&#x20;   public int hp;



&#x20;   public Player(string name, int hp)

&#x20;   {

&#x20;       this.name = name;

&#x20;       this.hp = hp;

&#x20;   }

}



new Player("Plum", 100)

&#x20;       ↓

Player 객체 생성

&#x20;       ↓

Player(string name, int hp) 생성자 실행

&#x20;       ↓

this.name = "Plum"

this.hp = 100



\----------------------------------------------------------------------------------------------



**-특징 :** 

이름이 클래스 이름과 같다.

반환형을 작성하지 않는다. (void도 작성하지 않음)

객체가 new를 통해 생성될 때 자동으로 호출된다.

주로 객체의 초기 상태를 설정하는 데 사용한다.

하나의 클래스에 여러 생성자를 만들 수 있다..



\----------------------------------------------------------------------------------------------



**-기본 생성자 :** 

매개변수가 없는 생성자

ex)

class Player

{

&#x20;   public int hp;



&#x20;   public Player()

&#x20;   {

&#x20;       hp = 100;

&#x20;   }

}



클래스에 생성자를 하나도 작성하지 않으면 C#이 매개변수가 없는 기본 생성자를 자동으로 제공한다.

하지만 생성자를 직접 하나라도 만들면 자동으로 기본 생성자가 만들어지지 않는다.



\----------------------------------------------------------------------------------------------



**-생성자 오버로딩 :**



ex)

&#x20;public Player()

&#x20;   {

&#x20;       name = "Unknown";

&#x20;       hp = 100;

&#x20;   }



&#x20;   public Player(string name)

&#x20;   {

&#x20;       this.name = name;

&#x20;       hp = 100;

&#x20;   }



&#x20;   public Player(string name, int hp)

&#x20;   {

&#x20;       this.name = name;

&#x20;       this.hp = hp;

&#x20;   }





new Player();

new Player("Plum");

new Player("Plum", 200);



\----------------------------------------------------------------------------------------------



**-this :** 

ex)

class Player

{

&#x20;   public string name;

&#x20;   public int hp;



&#x20;   public Player()

&#x20;       : this("Unknown", 100)

&#x20;   {

&#x20;   }



&#x20;   public Player(string name, int hp)

&#x20;   {

&#x20;       this.name = name;

&#x20;       this.hp = hp;

&#x20;   }

}

this 안 쓰면 여러 생성자에서 똑같은 초기화 코드 중복 작성해야 하는데 이렇게 하면 초기화를 담당하는 다른 생성자를 호출해 초기화를 대신 맡겨 한 곳에서 관리 가능
