###### **소멸자 (Destructor) :**

객체가 더 이상 필요 없어져 메모리에서 정리될 때 실행될 수 있는 특별한 메서드

Garbage Collector(GC)가 객체를 정리하는 과정에서 소멸자를 호출한다.



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public Player()

&#x20;   {

&#x20;       Console.WriteLine("생성자 실행");

&#x20;   }



&#x20;   \~Player()

&#x20;   {

&#x20;       Console.WriteLine("소멸자 실행");

&#x20;   }

}



\----------------------------------------------------------------------------------------------



**-특징 :** 

이름은 클래스 이름과 같음

앞에 \~를 붙임

반환형이 없음

매개변수를 받을 수 없음

접근 제한자를 사용할 수 없음

직접 호출할 수 없음

GC에 의해 호출 시점이 결정됨

객체가 null이 됐다 해서 즉시 소멸자가 실행되는 것이 아니라 소멸자의 실행 시점은 예측 불가능

C#에는 Garbage Collector가 있기 때문에 일반적인 객체의 메모리를 직접 해제할 필요가 없다.
