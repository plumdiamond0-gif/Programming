**static :**

특정 객체에 소속되지 않고, 클래스 자체에 소속되도록 만드는 키워드

일반 멤버 = 객체마다 따로 존재

static 멤버 = 클래스에 하나만 존재



\----------------------------------------------------------------------------------------------



**-일반 맴버와 차이 :**

일반 : 각 체는 서로 다른 필드 값을 가지고 있다.

static : 객체마다 존재하는 것이 아니라 클래스에 하나만 존재한다.



\----------------------------------------------------------------------------------------------



**-특징 :** 

객체를 만들 필요 없이 맴버를 클래스 이름을 통해 접근한다.

ex)

class MathUtility

{

&#x20;   public static int Add(int a, int b)

&#x20;   {

&#x20;       return a + b;

&#x20;   }

}

\-> 필드 변수가 객체마다 따로 있는 게 아니라 클래스에 하나만 있기 때문





static 메서드에서는 객체의 일반 멤버를 바로 사용할 수 없다

ex)

class Player

{

&#x20;   public int hp;



&#x20;   public static void Test()

&#x20;   {

&#x20;       hp = 100; // X

&#x20;   }

}

\->  어떤 객체의 hp를 수정해야 하는지 알 수 없기 때문
