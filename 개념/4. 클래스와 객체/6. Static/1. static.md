**static :**

특정 객체에 소속되지 않고, 클래스 자체에 소속되도록 만드는 키워드

일반 멤버 = 객체마다 따로 존재

static 멤버 = 클래스에 하나만 존재



\----------------------------------------------------------------------------------------------



**-일반 맴버와 차이 :**

일반 : 각 체는 서로 다른 필드 값을 가지고 있다.

static : 객체마다 존재하는 것이 아니라 클래스에 하나만 존재한다.



\----------------------------------------------------------------------------------------------



**-특징 :**

객체를 만들 필요 없이 맴버를 클래스 이름을 통해 접근한다.

this 사용 불가능



\----------------------------------------------------------------------------------------------



**-static 필드 :**

ex)

class Player

{

&#x20;   public static int playerCount;



&#x20;   public Player()

&#x20;   {

&#x20;       playerCount++;

&#x20;   }

}

Player player1 = new Player(); 

Player player2 = new Player();

Player player3 = new Player();



Console.WriteLine(Player.playerCount);



\-> 3



필드가 객체마다 따로 있는 게 아니라 클래스에 하나만 있기 때문



\----------------------------------------------------------------------------------------------



**-static 메서드 :**

ex)

class MathUtility

{

&#x20;   public static int Add(int a, int b)

&#x20;   {

&#x20;       return a + b;

&#x20;   }

}

int result = MathUtility.Add(10, 20);



객체를 만들 필요 없이 클래스 이름으로 바로 호출 가능

특정 클래스 객체에 속하지 않기 떄문에 클래스 객체의 일반 멤버를 바로 사용할 수 없음.
