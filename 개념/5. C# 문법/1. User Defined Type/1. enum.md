**Enum(열거형) :**

서로 관련 있는 여러 개의 값을 하나의 타입으로 묶어서 이름을 붙여 관리하는 자료형



\----------------------------------------------------------------------------------------------



**-ex) :** 

enum WeaponType

{

&#x20;   Sword,

&#x20;   Gun,

&#x20;   Bow

}



\----------------------------------------------------------------------------------------------



**-필요 이유 :**

미리 정의된 값만 사용할 수 있게



\----------------------------------------------------------------------------------------------



**-특징 :** 



값이 내부적으로 숫자다

0부터 1씩 증가하며 직접 지정하기도 가능

이후 값을 생략하면 1씩 증가

ex)

enum WeaponType

{

&#x20;   Sword, // 0

&#x20;   Gun,   // 1

&#x20;   Bow    // 2

&#x20;   Axe = 26

&#x20;   Hammer //27

}



switch와의 연계성이 좋음. -> 종류에 따라 다른 행동 실행 용이



\----------------------------------------------------------------------------------------------



**-class와의 차이  :**

||enum|class|
|-|-|-|
|목적|정해진 선택지 표현|객체의 데이터와 기능 표현|
|값|제한된 여러 선택지|여러 필드와 메서드|
|객체 생성|X|O|
|대표 사용|상태, 종류, 타입|플레이어, 적, 무기|
||||
