**readonly :**

한 번 값을 설정한 뒤, 이후에는 값을 변경할 수 없도록 만드는 키워드



\----------------------------------------------------------------------------------------------



**-ex) :**

public readonly int maxHealth = 100;



\----------------------------------------------------------------------------------------------



**-특징 :** 



다른 곳에서 값 변경은 불가능하나 읽는 것은 가능



생성자에서 변경 가능

선언시 초기화하거나 생성자에서 설정한 이루 값이 확정되고 이후에 변경 불가능해짐



List 객체 자체를 수정하지 못하게 하는 게 아니라, 변수가 가리키는 참조를 다른 객체로 바꾸지 못하게 하는 것이기 때문에 참조 자체를 변경하는 게 불가능함.

\----------------------------------------------------------------------------------------------



**-const와의 차이 :** 

const는 컴파일 시점부터 값이 완전히 고정되고 선언하ㄹ 때 반드시 값 넣어해 함

||const|readonly|
|-|-|-|
|값 변경|X|X|
|선언할 때 초기화|O|O|
|생성자에서 초기화|X|O|
|객체마다 다른 값|X|O|
|컴파일 시 값 확정|O|X|
|주 사용 목적|완전히 고정된 상수|생성 후 고정되는 값|





ex)

중력처럼 게임 전체에서 절대 변하지 않는 값은 const가 적합하고,

객체마다 생성될 때 결정되는 값은 readonly가 적합



\----------------------------------------------------------------------------------------------



**-static readonly :**

클래스에서 바로 접근하면서도 값을 변경하지 못함



\----------------------------------------------------------------------------------------------
