**Nullable :**

원래 null을 가질 수 없는 값도 null을 가질 수 있게 만드는 것



\----------------------------------------------------------------------------------------------



**-ex) :**

string name = null;

int age = null; // X

\-> 참조형에서는 null 값 지정이 가능하지만 값 자체를 저장하는 값형에서는 불가능



Nullable<int> age = null;

int? age = null;



\----------------------------------------------------------------------------------------------



**-필요 이유 :**  

ex) :

int score = 0;



점수가 0인지, 아직 점수 측정을 안 한지 구분 어러움



\----------------------------------------------------------------------------------------------



**-값 확인 :** 

nullable.Hasvalue

로 값이 존재하는지 확인 가능

nullable.Value는 실제 값을 가져오는데 null인 nullable에 사용하면 예외 발생



\----------------------------------------------------------------------------------------------



**-특징 :**
