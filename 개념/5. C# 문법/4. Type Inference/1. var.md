**var :**

변수의 타입을 컴파일러가 오른쪽 값을 보고 자동으로 결정하게 하는 키워드



\----------------------------------------------------------------------------------------------



**-ex) :**

var age = 19;

var name = "Plum";

var speed = 5.0f;

컴파일할 때 타입이 결정



\----------------------------------------------------------------------------------------------



**-특징 :** 



var number = 10;

타입을 생략하는 것이기에 개념적으로 

int number = 10; 와 같음

\-> 

처음에 결정된 타입을 이후에 바꾸기 불가능



반드시 초기값 필요



타입이 없는 것이 아니라 컴파일러가 추론하는 것



타입이 명확하게 보이는 경우에 사용하는 게 좋음

특히 타입 이름이 길어질수록 편리.
