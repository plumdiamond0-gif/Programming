**is :**

어떤 객체나 값이 특정 타입인지 확인하는 연산자



\----------------------------------------------------------------------------------------------



**-ex) :**

object value = "Hello";

if (value is string)

{

&#x20;   Console.WriteLine("문자열입니다.");

}



\----------------------------------------------------------------------------------------------



**-특징 :** 

ex)

class Character

{

}

class Player : Character

{

}

Character character = new Player();

클래스의 상속에서 변수가 실제로 어떤 객체를 가라키는지 확인할 때 유용



단순히 정확히 같은 타입인지만 확인하는 것이 아니라 해당 타입으로 취급할 수 있는 상속 관계인지도 확인한다.



is not도 가능



값 타입에도 사용 가능



\----------------------------------------------------------------------------------------------



**-패턴 변수 :** 

ex)

object value = "Hello";



if (value is string text)

{

&#x20;   Console.WriteLine(text.Length);

}

타입 확인과 동시에 해당 타입의 변수로 받아올 수 있다.



\----------------------------------------------------------------------------------------------



**-as와의 차이 :** 

is : 타입인지 확인

as : 해당 타입으로 반환을 시도
