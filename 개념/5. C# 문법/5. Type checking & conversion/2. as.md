**as :**

객체를 특정 타입으로 변환(참조 변환)해보는 연산자



\----------------------------------------------------------------------------------------------



**-ex) :**

object value = "Hello";

string text = value as string;



변환 불가능 -> null



\----------------------------------------------------------------------------------------------



**-특징 :** 



ex)

class Character

{

}

class Player : Character

{

&#x20;   public void Attack()

&#x20;   {

&#x20;       Console.WriteLine("공격!");

&#x20;   }

}

class Enemy : Character

{

}



Character character = new Player();

\-> 변수의 타입은 Character이지만 실제 객체는 Player



Player player = character as Player;

\-> Player로 변환할 수 있기 때문에 성공

클래스 상속에서 자주 사용





Character character = new Enemy();

Player player = character as Player;

\-> 실제 객체는 Enemy므로 변환 불가능









모든 타입 변환에는 사용 불가능

주로 참조형이나 nullable 값 타입 등에 사용 가능





\----------------------------------------------------------------------------------------------



**-일반적인 캐스팅과의 차이 :**



변환 불가능 ->

일반 캐스팅 : 예외 발생

as : null
