**typeof :**

특정 타입(Type) 자체에 대한 System.Type 객체를 가져오는 연산자



\----------------------------------------------------------------------------------------------



**-ex) :** 

Type type = typeof(int);

ypeof(int)는 int라는 타입 자체의 정보를 나타내는 Type 객체를 반환한다.



\----------------------------------------------------------------------------------------------



**-특징 :** 



클래스에도 사용 가능



제네릭에서 자주 사용

ex)

void PrintType<T>()

{

&#x20;   Console.WriteLine(typeof(T));

}

T가 어떤 타입으로 결정됐는지 확인

\----------------------------------------------------------------------------------------------



**-GetType()과의 차이 :**



typeof : 코드에서 타입을 직접 지정, 객체 없이도 사용 가능

GetType() : 이미 존재하는 객체의 실제 타입을 가져옴.



\----------------------------------------------------------------------------------------------





Character character = new Player();



character is Player

→ Player인가?



character as Player

→ Player로 사용할 수 있나?



typeof(Player)

→ Player 타입의 정보 가져오기



character.GetType()

→ character가 실제로 어떤 타입의 객체인지 가져오기
