**nameof :**

변수, 메서드, 클래스, 프로퍼티 등의 이름을 문자열(string)로 가져오는 연산자



\----------------------------------------------------------------------------------------------



**-ex) :** 

string name = nameof(Player);

name = "Player"



int hp = 100;

Console.WriteLine(nameof(hp)); //hp



메서드랑 프로퍼티에도 동일한 방식으로 사용 가능



\----------------------------------------------------------------------------------------------



**-특징 :** 



이름을 직접 적는 것보다 안전 -> 나중에 변수 이름 변경했을 때 자동으로 변경



실제 값을 가져오는 것이 아니라 이름만 가져오는 것

\----------------------------------------------------------------------------------------------
