**Namespace :**

클래스, 변수, 인터페이스 등의 이름을 묶어서 관리하는 공간



\----------------------------------------------------------------------------------------------



**-필요 이유 :** 

namespace Game

{

&#x20;   class Player

&#x20;   {

&#x20;   }

}

namespace Editor

{

&#x20;   class Player

&#x20;   {

&#x20;   }

}

서로 다른 이름의 클래스 구분하기 위함



\----------------------------------------------------------------------------------------------



**-선언 :** 

ex)

namespace Game

{

&#x20;   class Player

&#x20;   {

&#x20;       public void Attack()

&#x20;       {

&#x20;           Console.WriteLine("공격!");

&#x20;       }

&#x20;   }

}

Game.Player



\----------------------------------------------------------------------------------------------



**-사용 :** 

Game.Player player = new Game.Player();

다른 곳에서 사용하려면 전체 이름을 적는다



using Game;

Player player = new Player();

하지만 using을 사용하면 다른 네임스페이스 안에서 바로 사용 가능
