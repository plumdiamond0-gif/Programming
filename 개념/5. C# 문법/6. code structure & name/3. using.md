**using :**

Namespace를 가져와서 이름을 짧게.



\----------------------------------------------------------------------------------------------



**-ex) :** 

using System;

Console.WriteLine("Hello");



\----------------------------------------------------------------------------------------------



**-특징 :** 

클래스들이 복사되거나 새로 생성되는 게 아니라 

namespace 이름 생략해서 써도 찾아달라 알려주는 것.



\----------------------------------------------------------------------------------------------



**-별칭(Alias) :**

ex) 

using GamePlayer = Game.Player;

GamePlayer player = new GamePlayer();



이름이 너무 길거나 이름 충돌이 있을 때 유용
