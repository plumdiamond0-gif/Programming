**Class :**

객체를 만들기 위한 설계도이면서, 객체가 가져야 할 상태와 행동을 정의하는 틀



\----------------------------------------------------------------------------------------------



**-ex) :**

class Player

{

&#x20;   public string name;

&#x20;   public int hp;

&#x20;   public float speed;



&#x20;   public void Attack()

&#x20;   {

&#x20;       Console.WriteLine("공격!");

&#x20;   }



&#x20;   public void Move()

&#x20;   {

&#x20;       Console.WriteLine("이동!");

&#x20;   }

}



상태(State) : name, hp, speed

행동(Behaivor) : Attack(), Move()



\----------------------------------------------------------------------------------------------



**-객체 지향에서 :**

객체 지향에서는 프로그램을 단순히 함수들의 모음으로 보는 것이 아니라,

서로 역할을 가진 객체들이 상호작용하는 구조로 만들려고 한다.

데이터와 기능을 하나로 묶음



각 객체의 역할과 책임을 클래스로 정의하는 것



\----------------------------------------------------------------------------------------------



**-객체와의 관계 :**

클래스는 객체가 어떤 구조를 가져야 하는지 정의한 것

ex)

player1.hp = 100;

player2.hp = 50;

각각 독립적인 상태 가짐
