**객체(Object) :**

클래스에 정의된 내용을 바탕으로 실제로 만들어진 하나의 실체



\----------------------------------------------------------------------------------------------



**-ex) :**

Player player = new Player();



클래스 = 설계도

객체 = 설계도로 실제 만들어진 것



\----------------------------------------------------------------------------------------------



**-특징 :**

상태와 행동을 가진다



상태(State) : 객체가 현재 가지고 있는 데이터

행동(Behavior) : 객체가 할 수 있는 동작



같은 클래스에서 여러 객체 만들기 가능



객체끼리 서로 상호작용함

객체가 다른 객체의 기능을 호출하면서 프로그램이 동작



참조형이다

\----------------------------------------------------------------------------------------------



**-변수와의 차이 :**

ex)

Player player = new Player();



Player 객체의 타입

player 객체를 가리키는 참조 변수

new Player() 실제로 객체를 생성하는 부분
