**캡슐화(Encapsulation) :**

객체의 내부 상태와 구현을 외부에서 함부로 건드리지 못하게 하고, 객체가 자신의 상태를 스스로 관리하도록 만드는 것



\----------------------------------------------------------------------------------------------



**-필요 이유 :**



ex)

class Player

{

&#x20;   public int hp;

}

\-> 외부에서 값을 마음대로 변경 가능



class Player

{

&#x20;   private int hp;

}

\-> 외부에서 접근 불가능하고 Player 내에서만 관리 가능



class Player

{

&#x20;   private int hp = 100;



&#x20;   public void TakeDamage(int damage)

&#x20;   {

&#x20;       hp -= damage;



&#x20;       if (hp < 0)

&#x20;           hp = 0;

&#x20;   }

}

\-> 메서드를 통해 접근하게 가능

\----------------------------------------------------------------------------------------------



**-특징 :**

프로퍼의 get과 set도 캡슐화에 사용됨



잘못된 데이터 변경 방지

내부 구현 숨김

코드 수정 용이

객체가 자신의 상태 책임지게 함
