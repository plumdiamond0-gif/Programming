**상속(Inheritance) :**

기존 클래스의 특징(데이터와 기능)을 새로운 클래스가 물려받는 것



\----------------------------------------------------------------------------------------------



**-ex):**

class Character

{

&#x20;   public int hp;



&#x20;   public void Move()

&#x20;   {

&#x20;       Console.WriteLine("이동");

&#x20;   }

}



class Player : Character

{

}

Character → 부모 클래스(Base Class)

Player → 자식 클래스(Derived Class)



자식 클래스는 부모 클래스의 맴버를 물려받아 사용 가능



\----------------------------------------------------------------------------------------------



**-필요 이유 :**

각기 다른 클래스의 중복된 내용을 하나의 부모 클래스로 묶기 위해



코드 재사용

관계 표현

기능 확장

다형성



\----------------------------------------------------------------------------------------------



**-특징 :** 



자식은 자신만의 기능도 추가 가능





부모의 기능도 변경 가능

ex)

class Character

{

&#x20;   public virtual void Attack()

&#x20;   {

&#x20;       Console.WriteLine("일반 공격");

&#x20;   }

}

class Player : Character

{

&#x20;   public override void Attack()

&#x20;   {

&#x20;       Console.WriteLine("플레이어 공격");

&#x20;   }

}

virtual → 자식이 변경할 수 있도록 허용

override → 부모의 기능을 자식이 재정의





부모 클래스에 생성자가 있다면 자식 객체를 만들 때 부모 생성자도 실행됨



접근 제한자에 의해 부모 기능 모두 사용가능한 건 아님



\----------------------------------------------------------------------------------------------

Player is a Character

Enemy → Character

\-> 둘 다 Character의 일종
