**다형성(Polymorphism) :**

하나의 부모 타입으로 여러 종류의 자식 객체를 다룰 수 있고, 같은 메서드 호출이라도 실제 객체에 따라 다른 동작을 하게 만드는 것



\----------------------------------------------------------------------------------------------



**-ex):**

class Character

{

&#x20;   public virtual void Attack()

&#x20;   {

&#x20;       Console.WriteLine("캐릭터 공격");

&#x20;   }

}



class Player : Character

{

&#x20;   public override void Attack()

&#x20;   {

&#x20;       Console.WriteLine("플레이어가 검으로 공격");

&#x20;   }

}



class Enemy : Character

{

&#x20;   public override void Attack()

&#x20;   {

&#x20;       Console.WriteLine("적이 발톱으로 공격");

&#x20;   }

}



1. 상속을 통한 다형성
2. 메서드 오버로딩





\----------------------------------------------------------------------------------------------



**-특징 :**



ex)

Character character = new Player();

character.Attack();

부모 타입으로 자식 객체를 참조할 수 있다



ex)

Character player = new Player();

Character enemy = new Enemy();



player.Attack(); -> 플레이어가 검으로 공격

enemy.Attack(); -> 적이 발톱으로 공격



같은 매서드라도 객체에 따라 결과가 다름

\->

호출하는 코드는 하나인데 실제 동작은 객체마다 다르게 하기 가능
