###### **RAM(Random Access Memory) :** 

CPU가 프로그램을 실행하는 동안 필요한 코드와 데이터를 임시로 저장하는 주기억장치



**-프로그램 실행 과정에서 RAM의 위치 :** 

저장장치

&#x20; │

&#x20; │ 프로그램 파일

&#x20; ▼

RAM

&#x20; │

&#x20; │ 실행에 필요한 코드와 데이터

&#x20; ▼

CPU

&#x20; │

&#x20; │ 명령 처리

&#x20; ▼

프로그램 동작



컴퓨터에 저장되어 있는 프로그램을 실행하면 운영체제가 프로그램을 실행하는 데 필요한 내용들을 RAM에 적재하고, 

CPU가 RAM에 있는 코드와 데이터를 이용해 프로그램을 실행한다.



**-RAM 사용 이유 :** 

CPU는 매우 빠르게 연산할 수 있지만, 저장장치(SSD/HDD)는 CPU에 비해 상대적으로 느리다.

따라서 실행 중인 프로그램의 데이터를 RAM에 올려두고 CPU가 빠르게 접근할 수 있도록 한다.

게임 파일

&#x20;  ↓

RAM에 필요한 데이터 적재

&#x20;  ↓

CPU가 데이터와 명령을 가져옴

&#x20;  ↓

게임 로직 실행

**-RAM과 프로세스의 관계 :**



프로그램

&#x20;  ↓ 실행

프로세스 생성

&#x20;  ↓

메모리 공간 확보

&#x20;  ↓

RAM에서 코드와 데이터 사용

&#x20;  ↓

CPU가 명령 처리

프로그램은 실행되면 프로세스가 되고, 프로세스는 RAM의 메모리 공간을 관리하고 사용하면서 실행된다.



**-RAM과 CPU의 관계 :**

&#x09;      CPU	                    								   RAM

역할	명령과 데이터를 처리				실행에 필요한 코드와 데이터를 저장

특징	연산 담당						임시 저장 담당

관계	RAM에서 필요한 데이터를 가져와 처리	CPU가 사용할 데이터를 제공



CPU가 RAM에서 데이터를 가져와 처리하고, 처리 결과를 다시 RAM에 저장할 수도 있다.



**-RAM 부족 :** 

운영체제가 저장장치의 일부를 가상 메모리 등으로 활용할 수 있지만, 일반적으로 RAM보다 느리기 때문에 성능이 떨어질 수 있다.



로딩이 느려질 수 있음

프로그램 간 전환이 느려질 수 있음

데이터가 자주 교체될 수 있음

심하면 프로그램이 정상적으로 실행되지 않을 수 있음
