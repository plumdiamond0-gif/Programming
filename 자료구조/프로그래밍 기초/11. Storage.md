###### **저장장치(Storage) :** 

저장장치는 프로그램과 파일 등의 데이터를 장기간 보존하는 비휘발성 저장 공간



**-역할 :** 

*1. 프로그램 저장* 

게임이나 프로그램을 설치하면 프로그램의 파일이 저장장치에 저장된다.



*2. 데이터 저장*

사용자가 만든 문서, 사진, 동영상, 음악, 게임 세이브 데이터 등의 파일도 저장한다.



*3. 전원이 꺼져도 데이터 유지*

SSD / HDD

→ 전원이 꺼져도 데이터 유지(비휘발성 저장장치)

RAM

→ 전원이 꺼지면 일반적으로 저장된 데이터가 사라짐



**-RAM과의 관계 :**

&#x20;  저장장치

&#x20;         (SSD / HDD)

&#x20;              │

&#x20;         프로그램 저장

&#x20;              │

&#x20;              │ 실행

&#x20;              ▼

&#x20;             RAM

&#x20;      실행에 필요한 코드와

&#x20;         데이터 적재

&#x20;              │

&#x20;              ▼

&#x20;             CPU

&#x20;         명령어 처리

&#x20;              │

&#x20;              ▼

&#x20;         프로그램 동작



게임을 실행하면 게임이 저장장치에 있는 상태에서 필요한 코드와 데이터를 RAM으로 가져오고, CPU가 RAM에 있는 내용을 이용해 게임을 실행



**-저장장치와 RAM의 차이**

&#x09;			저장장치						RAM

주요 역할			데이터를 장기간 저장				실행 중인 데이터 임시 저장

전원 OFF			데이터 유지						일반적으로 데이터 소실

대표적인 예			SSD, HDD						DDR4, DDR5 RAM

CPU와의 관계		직접적인 실행 공간이라기보다 데이터를 보관	CPU가 실행 중인 코드와 데이터에 빠르게 접근

용량				일반적으로 큼					저장장치보다 작음

속도				RAM보다 느림					저장장치보다 빠름
