###### **상수(Constant) :**

프로그램에서 한번 정해진 값을 변경하지 않고 사용하는 데이터



ex) 

const int MaxHp = 100;



const → 상수로 선언

int   → 자료형

MaxHp → 상수 이름

100   → 상수의 값



**-변수와 상수의 차이**

&#x09;	변수				상수

값 변경	가능				불가능

선언		int hp = 100;		const int MaxHp = 100;

목적		변하는 데이터 저장	변하지 않는 값 정의



**-쓰는 이유 :** 

프로그램에서 절대로 변하면 안 되는 값을 명확하게 표현하기 위해



매직 넘버(Magic Number) : 무엇을 의미하는지 코드만 보고 바로 알기 어려운 숫자

상수를 사용할 시 매직 넘버의 의미가 명확해짐.



**-특징 :** 

1\. 선언할 때 값을 지정

2\. 선언 이후 값을 변경할 수 없다





**-const와 readonly의 차이 :** 

const는 컴파일 타임 상수이고, readonly는 한번 초기화된 이후 변경할 수 없는 필드라는 차이가 있다.

ex)

class Player

{

&#x20;   const int MaxHp = 100;



&#x20;   readonly int playerId;



&#x20;   public Player(int id)

&#x20;   {

&#x20;       playerId = id;

&#x20;   }

}



MaxHp는 모든 객체에서 동일한 고정값이고, playerId는 객체가 생성될 때 결정된 후 변경되지 않는 값
