###### **자료형(Data Type) :** 

변수나 데이터가 어떤 종류의 값을 저장하고, 그 값을 어떻게 해석하고 처리할지를 나타내는 형식



**-필요 이유 :** 

각 데이터의 종류는 서로 다르기에 프로그램에게 각 데이터를 어떤 방식으로 저장하고 처리해야 하는지 알려주기 위해.



**종류(값형) :** 



*정수형 — int :* 

소수점이 없는 정수를 저장



*실수형 — float :*

소수점이 있는 숫자를 저장

(이동 속도, 중력, 위치 계산 등에 자주 사용)



*더 정밀한 실수형 — double :*

loat보다 더 높은 정밀도의 실수를 표현할 수 있다.



*논리형 — bool :* 

true, false

주로 조건을 판단할 때 사용한다.



*문자형 — char :*

하나의 문자를 저장한다.

문자는 작은따옴표를 사용한다.



*문자열형 — string :*

여러 문자로 이루어진 텍스트를 저장한다.



**-자료형과 변수의 관계 :**

ex)

int       hp       =       100

&#x20;↑         ↑                 ↑

자료형     변수 이름          값

hp라는 변수는 int 자료형의 데이터를 저장한다.



**-연산 결과 :**

ex)

int a = 10;

int b = 3;

int result = a / b; result = 3



float a = 10f;

float b = 3f;

float result = a / b; result = 3.33...



자료형에 따라 연산 결과가 달라질 수 있다.
