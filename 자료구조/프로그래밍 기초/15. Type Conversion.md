###### **Type Conversion :**

어떤 데이터를 다른 자료형의 데이터로 변환하는 것



**-필요 이유 :**

서로 다른 자료형을 계산할 때는 자료형을 적절하게 변환하거나, C#이 허용하는 규칙에 따라 한쪽을 다른 형태로 처리해야 한다.



**-종류 :**



*암시적 형 변환 :*

개발자가 직접 변환을 작성하지 않아도 컴파일러가 자동으로 변환하는 것

ex)

int number = 10;

long biggerNumber = number;

데이터 손실 가능성이 낮은 방향에서 가능



*명시적 형 변환 :*

개발자가 직접 어떤 자료형으로 변환할지 지정하는 것

ex)

float speed = 5.8f;

int intSpeed = (int)speed;

데이터 손실이 발생할 가능성이 있다.



**-데이터 손실**

ex)

float value = 10.9f;

int result = (int)value;



10.9

&#x20;↓

int 변환

&#x20;↓

10



자료형을 변환한다고 해서 원래 데이터가 항상 그대로 보존되는 것은 아니다.



**-문자열과 숫자 :** 



*문자열 ->  숫자*

ex)

int number = int.Parse("100");

if (int.TryParse("100", out int number))

{

&#x20;   // 변환 성공

}



*숫자 -> 문자열*

ex)

int number = 100;

string text = number.ToString();





\-캐스팅 :

ex)

float value = 10.5f;

int number = (int)value;

(int)value가 명시적 캐스팅(자료형을 지정하여 변환)

형 변환 = 더 넓은 개념

캐스팅 = 형 변환을 수행하는 특정 방법 중 하나
