###### **조건문(Conditional Statement) :**

프로그램에서 특정 조건이 참인지 거짓인지 판단하고, 그 결과에 따라 실행할 코드를 선택하는 문법



*역할 :*

상황에 따라 프로그램이 다른 행동을 하도록 만들어 실행 흐름을 제어



*원리 :*

ex)

if (condition)

{

&#x20;   실행문

}

condition

↓

조건을 판단

&#x20;  ↓

┌──────────────┐

│ true?        │

└──────┬───────┘

&#x20;      │

&#x20;  ┌───┴───┐

&#x20;  ↓       ↓

&#x20;true     false

&#x20;  ↓       ↓

&#x20;Die()   아무것도

&#x20;실행     하지 않음





*-if :*

if (condition)

{

&#x20;   실행할 코드

}



*-if - else :*

&#x20;         condition?

&#x20;         /     \\

&#x20;      true     false

&#x20;       ↓         ↓

&#x20;     Move()    Die()





*-if - else if - else :*



condition1 ?

&#x20;        │

&#x20;┌─┴─┐

true	 false

&#x20;│            │

Die()      ▼

&#x20;     	       condition2 ?

&#x20;     	       │     		 │

&#x09;     true  		false

&#x09;       │     		│

&#x09; 실행1        실행2



\-switch :



switch (Type)

{

&#x20;   case 1:

&#x20;       실행1

&#x20;       break;



&#x20;   case 2:

&#x20;       실행2

&#x20;       break;



&#x20;   case 3:

&#x20;       실행3

&#x20;       break;



&#x20;   default:

&#x20;       실행4

&#x20;       break;

}

enum이나 특정 상태를 처리할 때 유용



\-조건식 :

if ( ) 안의 내용

비교연산자나 논리연산자가 들어감





\-삼항연산자와 차이 :

조건문 -> 실행항 코드를 선택

삼항연산자 -> 사용할 값울 선택

삼항 연산자는 간단한 값을 선택할 때 유용하고, 여러 줄의 복잡한 작업을 수행해야 한다면 if문을 사용하는 것이 일반적이다
