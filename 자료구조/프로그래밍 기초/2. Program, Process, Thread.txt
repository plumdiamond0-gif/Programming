프로그램(Program) : 
컴퓨터가 무엇을, 어떤 순서로, 어떻게 처리할지 적어놓은 명령들의 모음

-수많은 명령과 데이터가 모여 하나의 프로그램을 구성.
-실행하기 위한 설계도.

----------------------------------------------------------------------------------------------

프로세스(Process) :
운영체제가 실행 중인 프로그램을 관리하기 위해 만든 실행 단위

-프로그램이 실제로 실행되고 있는 상태.
-프로세스가 만들어지면 운영체제는 해당 프로그램이 실행될 수 있도록 여러 자원을 할당.
{
메모리 공간
코드
데이터
스택
힙
프로그램 실행 상태
CPU 실행 정보
열려 있는 파일 등의 자원
프로세스를 식별하기 위한 PID(Process ID)
}
-게임을 실행하면 운영체제는 게임 프로세스에 메모리를 할당하고 CPU가 게임의 코드를 실행하도록 관리한다.

----------------------------------------------------------------------------------------------

스레드(Thread) : 
프로세스 안에서 실제로 명령을 실행하는 작업의 흐름

-각각의 스레드는 자신만의 실행 흐름을 가진다.
-프로세스 하나에는 하나 이상의 스레드가 존재할 수 있다.
-프로그램이 처음 실행될 때 만들어지는 기본적인 스레드를 보통 메인 스레드(Main Thread)라고 한다.

-여러 스레드를 사용하는 이유 :

하나의 스레드만 사용하면 작업을 순서대로 처리해야 한다.(대신 운영체제가 매우 빠르게 실행 대상을 바꾼다. -> 스레드 스케줄링)
작업 A -> 작업 B -> 작업 C -> 작업 D

여러 스레드를 사용하면 작업을 나누어 처리할 수 있다.
Thread 1 → 작업 A
Thread 2 → 작업 B
Thread 3 → 작업 C

-CPU의 여러 코어를 활용하면 실제로 여러 작업을 동시에 실행할 수도 있다.
(그래서 게임에서는 예를 들어 무거운 파일 처리나 계산 등을 별도의 스레드에서 처리해서 
메인 스레드가 게임 화면을 계속 부드럽게 처리하도록 만들 수 있다.)

----------------------------------------------------------------------------------------------

프로세스와 스레드의 핵심 차이 :

		프로세스			스레드
의미		실행 중인 프로그램		프로세스 안의 실행 흐름
관계		독립적인 실행 단위		프로세스에 소속됨
메모리		독립적인 메모리 공간	같은 프로세스의 메모리를 공유
생성 비용		비교적 큼			비교적 작음
통신		상대적으로 복잡		메모리 공유가 쉬움
예시		Unity 게임 프로세스	게임 로직/작업을 수행하는 실행 흐름

실행하지 않고 파일로만 존재
실제로 실행되어 CPU와 메모리를 사용

프로세스들은 기본적으로 서로 독립된 메모리 공간을 가지지만, 
같은 프로세스에 속한 스레드들은 프로세스의 메모리 자원을 공유한다.
