###### **CPU(Central Processing Unit, 중앙처리장치) :** 

프로그램의 명령을 가져와 해석하고 연산하여 실제 작업을 수행하는 컴퓨터의 핵심 처리 장치



**-CPU와 스레드 :** 

프로세스와 스레드가 실행해야 할 작업을 가지고 있다면, CPU는 그 작업의 명령을 실제로 처리하는 역할을 한다.



**-즉 CPU가 수행하는 대표적인 작업들 :**

명령어 가져오기

명령어 해석

산술 연산

논리 연산

데이터 이동

메모리 접근

프로그램의 실행 흐름 제어



**-CPU와 스레드의 관계 :**

스레드는 실행해야 할 명령의 흐름이고, CPU는 그 명령을 실제로 처리하는 하드웨어다.



프로세스

│

├── Thread 1 ──────┐

├── Thread 2 ──────┼──→ CPU

└── Thread 3 ──────┘



CPU는 운영체제의 스케줄링에 따라 실행할 스레드를 선택하고 해당 스레드의 명령을 처리한다.

CPU 코어가 여러 개라면 여러 스레드를 실제로 동시에 처리할 수도 있다.



CPU

├── Core 1 → Thread 1

├── Core 2 → Thread 2

├── Core 3 → Thread 3

└── Core 4 → Thread 4





**-CPU와 메모리의 관계 :** 

프로그램 실행에 필요한 코드와 데이터는 메모리(RAM)에 저장되어 있고, CPU는 필요할 때 메모리에서 데이터를 가져와 처리



&#x20;       RAM

&#x20;        │

&#x20;   데이터 / 코드

&#x20;        │

&#x20;        ▼

&#x20;      CPU

&#x20;        │

&#x20;     연산/처리

&#x20;        │

&#x20;        ▼

&#x20;     결과 저장



CPU 내부에는 레지스터(Register)와 캐시(Cache) 같은 더 빠른 저장 공간도 존재.



저장장치

&#x20;  ↓

&#x20;RAM

&#x20;  ↓

&#x20;Cache

&#x20;  ↓

&#x20;Register

&#x20;  ↓

&#x20; CPU



**CPU의 핵심 구성 요소 :**



*ALU(Arithmetic Logic Unit) :* 

산술 및 논리 연산을 담당



*CU(Control Unit(제어 장치)) :*

명령어를 해석하고 CPU의 여러 구성 요소가 어떤 작업을 해야 하는지 제어



*Register :* 

CPU 내부의 매우 빠른 저장 공간

현재 처리 중인 데이터나 명령과 관련된 값을 임시로 저장
